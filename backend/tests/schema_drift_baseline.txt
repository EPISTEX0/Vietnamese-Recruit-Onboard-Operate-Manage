#
# Every line here is a difference `alembic revision --autogenerate` would emit today
# between `SQLModel.metadata` and a database at `alembic upgrade head`. They are
# recorded, not approved: `docs/schema-drift-audit.md` sections 5.4 and 5.5 argue each
# one is harmless (no data loss, no integrity loss). The dangerous drift -- P0/P1/P2,
# plus the 14 performance indexes -- is already closed and is deliberately absent.
#
# `tests/test_schema_drift_ceiling.py` fails on any fingerprint NOT in this list, and
# only warns when a line here has been cleaned up. Text after `#` is a human note and
# is not compared; the fingerprint is the whole line before it.
#
# `modify_*` fingerprints carry the old and new value on purpose. Keyed on the column
# alone, `users.avatar_url` is an accepted `TEXT -> VARCHAR`, and narrowing the model to
# `VARCHAR(10)` -- an ALTER that truncates live data -- would reuse that same line and
# pass. `modify_comment` is the exception: prose, and harmless either way.
#
# Adding a line means "I looked at this diff and it is not a landmine". Removing lines
# is always safe. Measured at head 085, 2026-08-14: 64 diffs, 48 tables in metadata.
